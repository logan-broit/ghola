Connect Claude Code

Set up Chapterhouse memory in under 2 minutes

Prerequisites:

  • Claude Code CLI installed
  • Your Chapterhouse API key (format: ch_k1_...)

Run this command:

claude mcp add -s user -t http chapterhouse-memory \ https://YOUR_SERVER/mcp/stateless \ --header "Authorization: Bearer ch_k1_YOUR_API_KEY_HERE"

Replace YOUR_SERVER with your Chapterhouse server address and ch_k1_YOUR_API_KEY_HERE with your actual API key. Create one from My API Keys.
