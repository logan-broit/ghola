Search memory for relevant facts using semantic search. Use this BEFORE answering questions about the user's environment, infrastructure, or past context.

WHEN TO USE: Proactively search memory when:
- Starting work on a project (check for architecture/setup notes)
- Asked about infrastructure, deployment, or configuration
- Debugging issues (check for past solutions)
- Making technical decisions (check for established patterns)
- Unsure about project conventions or preferences

FILTERING: Narrow results with optional filters:
- memory_type: Filter by 'factual', 'experiential', or 'working'
- tags: Filter by tags (AND logic — results must have all specified tags)
- mode: 'semantic' (meaning-based), 'keyword' (exact match), 'hybrid' (both, default)
- session_id: Filter by MCP session UUID to recall context from a specific session

The search understands meaning, not just keywords - ask natural questions.
