**Hypothesis**: ts_rank is saturated at ~1.0 for 80%+ of candidates after concept enrichment
(iter 2), providing zero discrimination. ts_rank_cd uses cover density (proximity of matching

```

single-session-assistant R@5: 100%, 10.7%, 57.1% (89.3pp spread!)
```

ts_rank_cd AMPLIFIES the cross-engine embedding mismatch:
- With ts_rank (constant 1.0): ranking = pure cosine. Variance from cosine perturbations = 0.8pp.
- With ts_rank_cd (variable): ranking = cosine + term proximity. Term proximity is
  HIGHLY sensitive to which candidates enter the pool (determined by query embedding).
  Different query embeddings -> different pool composition -> wildly different ts_rank_cd
  values -> massive ranking swings.

## Key Constraints Discovered

- **ts_rank is saturated at 1.0 after concept enrichment**: Adding user-turn text to weight A
  (iter 2) caused ts_rank to return ~1.0 for 80%+ of candidates. The FTS weight (0.4) in the
  scoring formula is effectively wasted -- it adds a constant 0.305 to all candidates.
  **This means the scoring formula is effectively `content_match = 0.6 * cosine + 0.305`.**

- **ts_rank_cd provides real differentiation but amplifies embedding mismatch 34x**: Cover
  density ranking varies 0-0.46 (vs constant 1.0), and gold mnemes have 1.8x higher mean.
  But this variable signal interacts catastrophically with cross-engine embedding noise,
  producing 27.2pp variance (vs 0.8pp baseline).

- **Fixing the embedding server is a PREREQUISITE for FTS improvements**: Any change that
  makes FTS a variable (non-constant) signal will interact with the embedding mismatch.
  The FTS saturation acts as a natural DAMPER on embedding noise. Removing the damper
  without fixing the noise source makes things worse.

- **40% of failing gold mnemes are in the candidate pool (semantic top-30)**: The retrieval
  bottleneck for these is SCORING, not pool size. Pool expansion alone won't help.

- **70% of failing gold mnemes lack FTS match**: The plainto_tsquery AND requirement is too
  strict. Gold and query use different words for the same concepts (paraphrasing gap).

- **Pool size analysis**: Expanding from 30 to 100 would capture 63% of gold mnemes (vs 40%
  at 30), but many would still lose in scoring due to compressed score distributions.
