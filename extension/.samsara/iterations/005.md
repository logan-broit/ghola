# Iteration 5 (2026-04-11, samsara)

**What**: Temporal stop word stripping in lexical FTS filter. Modified lexical CTE's `@@`
filter to use a cleaned query (temporal framing words removed) while keeping original for
ts_rank ranking.

**Hypothesis**: AND-based `plainto_tsquery` fails on temporal queries because framing words
("ago", "weeks", "many") never appear in answer content. Stripping them relaxes the AND
conjunction. Encoding specificity (Tulving, 1972) -- temporal framing words are retrieval
cues with no corresponding encoding.

**Verification**: Nordstrom answer session moved from not-in-top-10 to rank 2 with cleaned
filter. Confirms hypothesis for that specific query.

**Result**: R@5 29.2% -> 28.4% (-0.8pp). REGRESSION. Net: gained 1 temporal query, lost 3.

**Root cause**: Modifying the existing lexical pathway changes pool composition for ALL queries.
The relaxed filter admits competing sessions that displace existing marginal hits. Three
temporal queries had answers at exactly rank 5 -- the change pushed each to rank 6.

**Key insight**: The correct approach is a SEPARATE additive pathway (new CTE, UNION ALL)
that only fires when the existing lexical pathway returns zero results. This preserves
baseline behavior while adding candidates for queries that fail the strict AND filter.
